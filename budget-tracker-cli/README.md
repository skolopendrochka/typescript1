# Budget Tracker CLI

Интерактивный CLI-контроллер для управления бюджетными счетами и транзакциями.

## Возможности

- Создание и удаление счетов
- Просмотр баланса и сводки по счетам
- Добавление и удаление транзакций (доходы и расходы)
- Экспорт транзакций в CSV-файлы
- Интерактивное меню с удобной навигацией

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Скомпилируйте TypeScript код:
```bash
npm run build
```

3. Запустите приложение:
```bash
npm start
```

Для разработки: `npm run dev`

## Использование

После запуска вы увидите главное меню со списком всех счетов. Используйте стрелки для навигации и Enter для выбора.

### Главное меню
- Выберите счёт для просмотра деталей
- Создайте новый счёт
- Выйдите из приложения

### Меню счёта
- Добавить транзакцию
- Удалить транзакцию
- Экспортировать в CSV
- Удалить счёт
- Вернуться к списку счетов
