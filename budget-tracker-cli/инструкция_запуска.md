# Инструкция по запуску проекта

## Подготовка среды

Если на вашем компьютере нет Node.js:

1. Откройте официальный сайт: https://nodejs.org/
2. Загрузите рекомендованную LTS-версию
3. Выполните установку и перезагрузите терминал
4. Проверка установки: выполните команды node --version и npm --version

## Развертывание приложения 

Выполните в терминале последовательно:

bash
cd c:\Users\katya\Downloads\budget-tracker-cli
npm install
npm run build
npm start

Для разработки: `npm run dev`

## Работа с приложением

Основное меню позволяет:
- Перейти к существующему счёту
- Добавить новый счёт
- Завершить работу

Внутри счёта доступны действия:
- Внести операцию
- Удалить транзакцию
- Выгрузить данные в CSV-формат
- Удалить счёт
- Вернуться к списку счетов

Важно: При первом запуске система автоматически создаёт два демонстрационных счёта с примерными операциями.
