КРАТКАЯ ИНСТРУКЦИЯ ПО ЗАПУСКУ – Консольное приложение «Учет бюджета»

Предварительное требование: Наличие установленной среды Node.js (https://nodejs.org/)

Шаги для запуска:

Перейдите в директорию проекта через командную строку (терминал):
cd c:\Users\katya\Downloads\budget-tracker-cli

Установите необходимые библиотеки командой:
npm install

Выполните сборку проекта:
npm run build

Запустите приложение:
npm start

После успешного старта откроется интерактивное меню с двумя тестовыми счетами. Для работы в меню используйте клавиши-стрелки для перемещения и Enter для подтверждения выбора.
